# Build Guide

This project generates two types of outputs: a full application server and standalone HTML pages.

## Build Commands

### Full Build (Server + Static Pages)
```bash
npm run build
```

**What gets generated:**
- **`dist/`** — Production server and client files
  - `index.cjs` — Node.js server bundle (standalone executable)
  - `public/index.html` — Client entry point (served by server)
  - `public/assets/` — CSS, JS bundles (generated by Vite)
- **`dist_single/`** — Standalone HTML files (ready to distribute)
  - `AIEngineeringCopilotTraining.html` — Main training app (all-in-one, 601KB)
  - `AIEngineeringCopilotPrerequisite.html` — Prerequisites checklist (19KB)

### Development Server
```bash
npm run dev
```

Starts the dev server at `http://localhost:5173`

## Output Folders

### `dist/` — Full Application Server
Use this for running the Express server with full functionality.

**When to use:**
- Local testing and development
- Server-side applications
- Running in a Node.js environment

**Start the server:**
```bash
node dist/index.cjs
```

**Server runs on:** `http://localhost:3000`

### `dist_single/` — Static HTML Pages
Standalone, self-contained HTML files with everything bundled inline (CSS, JS, fonts, assets). **No server required.**

**When to use:**
- Hosting on GitHub Pages or static CDN
- Distributing training materials as standalone files
- Email attachments or offline viewing
- Sharing without requiring Node.js

**Usage:**
Simply open the HTML files directly in a browser.

## Files Generated

All React components are automatically converted to static HTML during the build:

- `AIEngineeringCopilotTraining.html` — Compiled from the full React app (includes all modules)
- `AIEngineeringCopilotPrerequisite.html` — Generated from ModulePrereq component (auto-updated when you change it)

### How It Works

1. **React components** → **TypeScript** → **Vite builds them** → **Two outputs:**
   - Normal app (for server): `dist/public/index.html`
   - Standalone pages (for distribution): `dist_single/AI*.html`

2. **Prerequisite generation**: The ModulePrereq component is rendered to HTML via `script/generate-prereq-html.ts`

3. **One build command** handles everything: `npm run build`

## Build Pipeline Summary

```
npm run build
├── rm dist, dist_single (clean)
├── Vite build (client app → dist/public/)
├── esbuild (server → dist/index.cjs)
├── Vite singlefile build (standalone → dist_single/index.html)
├── Generate prerequisite HTML → dist_single/AIEngineeringCopilotPrerequisite.html
└── Rename files to final names (index.html → AIEngineeringCopilot*.html)
```

## Clean Source Directory

**`client/public/`** contains only static assets (favicon, social images). No HTML files to maintain—everything is auto-generated from React components.
